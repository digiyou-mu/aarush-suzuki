# Suzuki Pro font files go here

The site's CSS (`/assets/css/site.css`) loads these exact filenames:

| Weight | Used for | Filename (any of these formats) |
|---|---|---|
| 700 (SuzukiProBold) | Headings, section titles, short highlights, labels | `SuzukiPro-Bold.woff2` / `.woff` / `.ttf` / `.otf` |
| 400 (SuzukiProRegular) | Paragraphs, navigation, buttons, forms, specs | `SuzukiPro-Regular.woff2` / `.woff` / `.ttf` / `.otf` |

Suzuki Pro is Suzuki's proprietary corporate typeface. Use the files supplied by Suzuki Motorcycle India's dealer brand kit; the dealership's licence must cover web embedding.

Once the files are here, uncomment the two `<link rel="preload">` lines in each page's `<head>` for the `.woff2` files.
